# STM32F103C8T6 Driver Documentation

This generated site is the navigation and API-reference entry point for the
repository's reviewed peripheral drivers. Long-form hardware theory,
architecture, register semantics, layer ownership, and implementation mapping
live in each peripheral's canonical guide.

Every guide first teaches **Theory with Register Mapping Bridge**, then maps it
to the repository through **Implementation with Theory Bridge**. Source API
Doxygen links to these guides and retains only local callable contracts, so the
theory has one maintained source.

Additional peripheral guides are added here only after their architecture page
is current, reviewed, included by Doxygen, and linked from the peripheral's
public Driver and LL groups.

## API reference

Use the generated **Modules**, **Files**, and **Data Structures** sections for
function signatures, accepted values, return contracts, types, macros, and
register structures. Those pages remain concise and link back to the relevant
peripheral guide for full theory and architectural reasoning.

## Documentation boundary

Planning audits, TODO lists, historical implementation snapshots, and mutable
working notes are intentionally not published as canonical project
documentation. They must be reviewed and promoted to a peripheral guide before
being linked from this page.
